# Use of AI in MarsNav

NASA Space Apps asks every team to disclose its use of AI. This file is that disclosure for the repository.

## What AI was used for

MarsNav was developed with an AI coding assistant, Anthropic's Claude, used throughout the project.

| Area | AI involvement | What stayed with the team |
|---|---|---|
| Source code (`engine/`, `planet/`, `pipeline/`, `launcher/`, `app/`) | Wrote and refactored much of the code, and helped debug it | The design decisions, safety rules, data choices and acceptance of every change |
| Tests (`tests/`) and validation scripts (`validation/`) | Wrote much of the test and validation code | The choice of what to test against (Perseverance's records, NASA's TSS2027 server) |
| Documents (`README.md`, `docs/`, `submission/`, the user guide) | Drafted text from the team's results | Review of every claim against the code's output |
| User-guide screenshots | Captured automatically from the running app by scripts | Choice of scenes |

All source files in this repository should be treated as AI-assisted.

## What is not AI-generated

- **Data.** Every dataset is real mission data downloaded from its canonical source with a recorded SHA-256 checksum (`pipeline/sources.json`, `docs/04_data_and_provenance.md`).
- **Results.** Every number in the README, the documents and the submission comes from running the code on that data. Anyone can re-run them: `node --test tests/*.test.mjs`, `python -m pytest tests -q`, `node validation/validate.mjs`, `node validation/closed_loop_campaign.mjs`.
- **Images, video and audio.** None were generated by AI. Screenshots are captures of the running app.

No AI-generated content uses NASA logos or branding. MarsNav is an independent project and is not endorsed by NASA.
